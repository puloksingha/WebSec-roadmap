# Final Readiness Checklist

Before moving deeper into ethical hacking and penetration testing, make sure you can:

- [ ] Explain what cybersecurity is.
- [ ] Explain the CIA Triad with practical examples.
- [ ] Differentiate threats, vulnerabilities, exploits and risks.
- [ ] Explain how risk is calculated and prioritized.
- [ ] Identify different threat actors and their motivations.
- [ ] Explain preventive, detective and corrective controls.
- [ ] Differentiate authentication and authorization.
- [ ] Explain MFA, SSO, OAuth and JWT at a basic level.
- [ ] Explain RBAC, ABAC, DAC and MAC.
- [ ] Explain the Principle of Least Privilege.
- [ ] Explain Defense-in-Depth.
- [ ] Understand Zero Trust principles.
- [ ] Understand CVE, CVSS and CWE.
- [ ] Understand the MITRE ATT&CK framework.
- [ ] Understand basic incident response.
- [ ] Create a basic threat model for a web application.

**Final objective:** Understand how to identify security weaknesses, assess their impact, prioritize risks, and select appropriate security controls to protect applications, systems, networks, and data.
