# 1. Python Syntax

Python syntax is the set of rules for writing valid Python code.

### Example

```python
print("Hello World")
```

- Python reads code line by line.
- Each instruction usually goes on a new line.
- The code must follow Python's rules.
- If the syntax is wrong, Python shows an error.

### Example of a syntax error

```python
print("Hello World"
```

This is invalid because the closing parenthesis is missing.

---

# 2. Indentation

Python uses indentation to organize code.

```python
if 5 > 3:
    print("Five is greater than three")
```

- The space before `print()` is indentation.
- Python uses this indentation to know which code belongs to the block.
- Wrong indentation can cause an error.

---

# 3. Comments

Comments are notes written in the code for humans.
Python ignores comments when running the program.

### Single-line comment

```python
# This is a comment
print("Hello")
```

### Multi-line comment

```python
"""
This is a multi-line comment.
It can be used for longer notes.
"""
```

---

# 4. Why Use Comments?

Comments help us:

- explain code
- mark important parts
- make code easier to understand
- help other programmers and future you

### Example

```python
# Print a welcome message
print("Welcome to Python")
```

---

# 5. Best Practice

- Keep comments short and clear
- Do not write obvious comments
- Use comments to explain logic, not every line

### Good comment

```python
# Calculate total price after discount
```

### Bad comment

```python
# This line prints text
```

---

# Summary

- Python syntax must be written correctly.
- Indentation matters in Python.
- Comments are used to explain code.
- Comments do not affect program execution.
